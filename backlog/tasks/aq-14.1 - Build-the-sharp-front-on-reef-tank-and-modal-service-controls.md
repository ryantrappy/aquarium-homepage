## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The current homepage has a blurred, open-water treatment and visible service navigation that compete with the aquarium. This focused iteration builds the crisp front-on reef display environment and moves the service list behind a deliberate Services modal. It is a child of AQ-14 so this environment/layout slice can be reviewed independently; AQ-14 itself remains open until AQ-12 delivers lifelike photorealistic fish movement.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 The main screen shows a sharp, front-on view through reef-tank glass with clear perspective, clean water, deep focus, and crisp live rock, coral, and sand; it has no dark marketing scrim or blur and does not read as a blurry ocean vignette.
- [x] #2 The main view has no header, marketing title, permanent On the reef list, fixed dock, or app-card service list; the searchable service list appears only in a named native Services modal opened by deliberately activating the compact Services button.
- [x] #3 Only compact aquarium-themed Pause, Services, and Settings controls persist visibly; Escape closes the named modal, focus returns to its opener, and service launch plus transition from the Services modal to Settings work without nested focus traps.
- [x] #4 The habitat fills nearly the entire main view and remains the focus at the 402x874 CSS-pixel iPhone Pro proxy and 1440x900 laptop viewport, with compact controls usable and no permanent service list.
- [x] #5 Fish remain selectable links that open configured URLs in new tabs; current translating cutouts are treated as scaffold pending AQ-12 rather than counted as lifelike animation.
- [x] #6 The revised environment and Services modal are represented in an editable OpenPencil v2 source file and a reviewable preview.

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Build the main environment around the generated straight-on reef-tank image with clear water, true perspective, crisp deep focus, live rock, coral, and sand. Keep the existing background file available as a prior version; do not use a blurred or open-ocean vignette as the main tank.
2. Make the tank fill the viewport, remove the header, marketing hero, footer, persistent service dock, and permanent On the reef list, and overlay only compact Pause, Services, and Settings controls.
3. Put the searchable service list inside a named native Services modal opened only by deliberate activation of Services. Keep the settings dialog separate, avoid nested focus traps, and restore focus to the relevant opener on close.
4. Keep fish links clickable and opening the configured URL in a new tab. Treat translating cutouts as scaffold; AQ-12 owns lifelike fish locomotion.
5. Verify the layout only at 402x874 CSS pixels for the iPhone Pro proxy and 1440x900 for a normal laptop. Record root feedback on this task and iterate until approved.
