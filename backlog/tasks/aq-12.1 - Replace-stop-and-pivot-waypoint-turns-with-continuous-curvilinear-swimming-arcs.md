## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Fish currently appear to stop and spin on a single vertical axis at turns instead of carving continuous forward arcs. Direct inspection of `src/rendering/scene/motion.ts` and `src/rendering/scene/fish-turning.ts` (alongside the shared analysis at https://share.gemini.google/6848ZU7n1LUb) identifies the root causes:

1. Terminal braking on every waypoint (`motion.ts:773`): `Math.min(1, rawRemaining / .22)` decelerates fish toward zero at intermediate corners, not only the final waypoint.
2. Stacked turn-rate boosters during deceleration (`motion.ts:740-742`): `sharpTurnBoost` (1.65x) and `proximityTurnBoost` (2.2x) multiply angular turn rate up to 3.63x while speed is crushed, producing in-place spinning.
3. Mesh navigation disables lookahead (`motion.ts:735-737`): `habitat.meshNavigation !== undefined` bypasses `computeLookaheadTarget`, forcing sharp corner approaches.
4. Tight fixed lookahead fillet (`fish-turning.ts:225-228`): `filletRadius = 0.45` and max `0.48` blend start turning too late; `passedWaypoint` (`motion.ts:712`) also uses a fixed `0.35` radius instead of scaling with speed.
5. Hard speed zeroing on heading-blocked / chord-clear steps (`motion.ts:792-795`): `fish.speed = 0` halts momentum instead of decaying smoothly while recovering heading.
6. Aggressive `evaluateTurnSpeedFactor` and 65-degree `SHARP_TURN_THRESHOLD_RAD` (`fish-turning.ts:33,197-199`): normal turns drop speed too sharply instead of conserving momentum with curvature-locked yaw (`omega = v / R`).

Planned approach (do not implement in this task-creation step):
- Apply `rawRemaining / 0.22` arrival slowdown only when `fish.waypoint + 1 >= fish.route.length` (final waypoint), keeping cruise momentum through intermediate corners.
- Enable `computeLookaheadTarget` in mesh-navigation mode whenever `movementSafety(...) === 'clear'` for the lookahead point, falling back to `rawTarget` only when unsafe; scale `filletRadius` with `cruiseSpeed` and species rig archetype, and scale `passedWaypoint` radius with `fish.speed`.
- Cap angular turn rate by curvature (`v / minTurnRadius + hoverPivotAllowance`) instead of stacking `sharpTurnBoost * proximityTurnBoost` while stationary, and tune `SHARP_TURN_THRESHOLD_RAD` / `evaluateTurnSpeedFactor` so routine turns maintain forward glide.
- Replace hard `fish.speed = 0` on chord-clear obstacle recovery (`motion.ts:795`) with exponential speed decay (`Math.exp(-dt * k)`) while steering clear.
- Add feedforward lookahead curvature and inward `spine_0` roll banking so body flex and bank anticipate the arc.
<!-- SECTION:DESCRIPTION:END -->
