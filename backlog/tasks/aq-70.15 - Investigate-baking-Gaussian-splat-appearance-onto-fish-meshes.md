## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The user already has photorealistic Gaussian splats and wants to know whether their appearance can improve the existing fish mesh pipeline. The current splat-fish generator uses splat silhouettes and palettes as references to build procedural geometry and atlases; it does not project the original splat appearance. Investigate whether the user's original splat captures can produce useful UV texture detail on riggable meshes compatible with the Three.js/GLB scene. Locate and inspect the source splats when this task is picked up; do not assume the checked-in candidate GLBs contain the original splat data or that the source files may be redistributed.
<!-- SECTION:DESCRIPTION:END -->

### Gaussian Splat Input Verification & Technical Audit (2026-11-06)

#### 1. File & Storage Directives
- **Source Location**: `src/rendering/gaussian_splats/blue_tang.ply`
- **File Size**: 17,826,208 bytes (17.0 MB)
- **Persistence Constraint**: Provided explicitly by user as the core test fixture for AQ-70.15. **Must not be deleted or modified**. Excluded from production bundling/commits until license/permission is finalized.

#### 2. Binary PLY Format Specification
- **Format**: `binary_little_endian 1.0`
- **Vertex Count**: 262,144 Gaussian splats
- **Record Size**: 68 bytes/splat (17 × 4-byte `float32`)
- **Properties**:
  1. `x`, `y`, `z`: 3D position
  2. `nx`, `ny`, `nz`: Normal vector (direction)
  3. `f_dc_0`, `f_dc_1`, `f_dc_2`: Spherical Harmonics degree 0 (DC radiance, diffuse base color: `C = 0.5 + 0.28209479 * f_dc`)
  4. `opacity`: Logit opacity (`alpha = 1 / (1 + exp(-opacity))`)
  5. `scale_0`, `scale_1`, `scale_2`: Log scale axes of 3D Gaussian ellipsoid
  6. `rot_0`, `rot_1`, `rot_2`, `rot_3`: Unit quaternion rotation

#### 3. Spatial Bounds & Coordinate Orientation
- **Bounding Box**:
  - `X`: `[-0.4994, 0.4996]` (span: 0.9990) -> Swimming length axis. Snout at `+X` (~+0.50), caudal tail fin at `-X` (~-0.49).
  - `Y`: `[-0.3741, 0.3173]` (span: 0.6914) -> Dorsoventral height axis. Dorsal peak at `+Y` (~+0.25 to +0.31), ventral/anal at `-Y` (~-0.26 to -0.37).
  - `Z`: `[-0.1823, 0.1776]` (span: 0.3600) -> Lateral flank thickness axis.
  - Center: `(0.0001, -0.0284, -0.0024)`
- **Splat Density & Opacity Distribution**:
  - Opacity > 0.5: 227,719 splats (86.9%)
  - Opacity 0.1–0.5: 24,425 splats (9.3%)
  - Opacity < 0.1: 10,000 splats (3.8%)
  - Core body spans (1st–99th percentile of dense splats):
    - Length (X): 0.9321
    - Height (Y): 0.4364 (Height / Length ratio = 0.468)
    - Thickness (Z): 0.2089 (Thickness / Length ratio = 0.224)
- **Key Anatomical Landmarks in Splat Space**:
  - Snout tip: `[+0.4996, +0.0373, -0.0164]` (color: `[0.474, 0.487, 0.479]`)
  - Caudal tail tip: `[-0.4921, +0.0316, -0.0103]` (canary yellow: `[0.502, 0.488, 0.225]`)
  - Dorsal peak: `[+0.2237, +0.2512, -0.0674]` (deep blue/black margin)
  - Ventral lowest: `[+0.1853, -0.2563, -0.0090]`
  - Eye center: `[+0.3300, +0.0415, +0.1098]` (dense ocular cluster: 2,246 splats)

#### 4. Canonical Target Mesh Alignment (`src/rendering/assets/fish/fish-blue-tang.glb`)
- **Mesh Dimensions**: Width `0.0368m` (X), Height `0.0848m` (Z in Blender / Y in GLTF), Length `0.1527m` (Y in Blender / Z in GLTF).
- **Proportional Correspondence**:
  - Mesh Height/Length = `0.0848 / 0.1527 = 0.555` vs Splat `0.468` (close anatomical alignment; splat tail is slightly more compressed).
  - Mesh Thickness/Length = `0.0368 / 0.1527 = 0.241` vs Splat `0.224` (near-exact lateral proportion match).
- **Coordinate Transformation to Mesh**:
  - Rotate by +90° around Y (maps splat `+X` to mesh forward `+Z`, `+Y` to mesh up `+Y`).
  - Scale factor: approx 0.1527 / 0.9321 ≈ 0.1638 (scale splat to adult physical meters) or 6.104x to splat space.
  - KDTree lookup on the 262,144 splats completes build in 0.21s with query throughput of ~40,000 queries/sec.
