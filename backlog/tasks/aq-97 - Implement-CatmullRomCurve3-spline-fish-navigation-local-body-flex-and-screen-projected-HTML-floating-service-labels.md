## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Architect fish swimming navigation and interactive service dashboard presentation:
1. CatmullRomCurve3 Spline Navigation:
   - Generate smooth, continuous 3D paths using THREE.CatmullRomCurve3 that guide fish through realistic swimming loops across the full water column, threading through the NSA canyon and arches.
   - For body swimming flexion, apply natural sinusoidal bending along the local swim axis synchronized with swimming speed (via 2–3 bone armature or local-axis vertex shader).
2. 3D-Tracked Glassmorphic Service Labels:
   - Map 3D anchor points on each fish to screen coordinates using vector.project(camera).
   - Render clean CSS2D / HTML pill overlays with a subtle glassmorphic backdrop-filter: blur(8px) style, crisp typography, and an indicator status dot.
   - De-conflict labels so they remain tightly anchored near their fish without overlapping nearby fish or cluttering the view.
3. Accessibility & Controls:
   - Ensure clicking opens the configured service, keyboard navigation works seamlessly, and all movement/updates freeze on pause and reduced motion.
